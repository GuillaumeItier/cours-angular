Exercice : Interpolation de texte

Affichage de variables de différents types avec la syntaxe

1. Types primitifs

Note maximale :
{{maxScore}}  /  sur 20
Score actuel :
{{currentScore}} /  sur 20
Pourcentage :
{{ (currentScore / maxScore) * 100 }} %

2. Objet & Méthode

Rôle :
{{user.role}}
Nom complet (méthode) :
{{user.firstName}} {{user.lastName}}
Statut :
{{ isLoggedIn ? 'Connecté' : 'Déconnecté' }}

3. Tableaux (Array)

Première compétence (skills[0]) :
{{skills[0]}}
Toutes les compétences (.join) :
{{skills.join(' - ')}}
